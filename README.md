#Proyecto Biblioteca#

##Descripción##
Biblioteca con capacidad de gestión de catálogo, prestamos
de la biblioteca y consultas desde la web

##Estado del Proyecto##
Estructura inicial de java creada, por crear la base de 
datos y la web

##Funcionalidades previstas##
Añadir, eliminar, buscar,
retirar y devolver libro, portal web con capacidad de
búsqueda.

##Tecnologías en uso##
Java 25, Maven, PostgreSQL y HTML/CSS

##Motivación##
Practicar POO, acceso a base de datos, separación en
capas, conexión con una web.
